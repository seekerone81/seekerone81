Featured project

🛡️ PayGuard AI

PayGuard AI is a hackathon prototype exploring how a proposed purchase can be checked against a user's stated limits before a PayPal Sandbox order is created.

What I worked on: setting up the project, connecting its pieces, running and testing scenarios, debugging issues, iterating on the interface, and documenting the workflow—with AI-assisted guidance as part of my learning process.

What the prototype demonstrates:

A local Llama model is used to extract a structured purchase intent.

Python policy checks evaluate supported transaction rules such as budget and quantity.

A React interface presents product choices, policy results, and transaction history.

PayPal Sandbox demonstrates the order approval and payment flow.
